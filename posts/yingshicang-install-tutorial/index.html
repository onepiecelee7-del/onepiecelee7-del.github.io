影视仓所有版本的使用教程基本一致，下面分三步完成。

第一步：下载解压安装

我用夸克网盘分享了「影视仓TV99.apk」，点击链接或复制整段内容，打开「夸克网盘APP」即可获取：

第二步：点击安装到手机或者电视或者PC的模拟器

  • 手机：直接点击 APK 安装，提示”未知来源应用”时允许即可
  • 安卓电视/盒子：U 盘拷贝 APK 安装，或用侧载工具安装
  • PC 模拟器：模拟器安装包已在网盘里，直接保存下载；把 APK 拖进模拟器窗口即可安装

安卓电视和手机操作一样。装好后打开，主界面如下（PC 模拟器 BlueStacks 中的效果）：

第三步：配置入口

方法一：进入软件，点击”配置”

进入软件后点击查看”配置“里边：

  • 配置多仓地址 / 线路切换 / 配置地址，在配置地址处填入线路链接即可
  • 电脑端直接复制粘贴即可，等待几秒会自动加载新的页面即为成功
