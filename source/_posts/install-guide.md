# 影视仓/TVBox 安装配置教程

> 本站只分享线路工具和配置方法，不含任何影视内容资源。

## 一、获取软件和配置

1. 打开 **夸克网盘 / 迅雷网盘 / 百度网盘**（任选其一）
2. 在搜索框输入口令：**黑域无限**
3. 下载最新版软件安装包（APK）和配置文件

## 二、安装软件

1. 将 APK 传到电视/盒子上安装（U盘 或 当贝市场等侧载工具）
2. 手机端直接安装 APK 即可
3. 如提示"未知来源"，允许安装即可

## 三、导入线路配置

1. 打开影视仓 / TVBox
2. 进入 **设置 → 配置地址**
3. 删除旧地址，填入最新配置（配置文件里有说明）
4. 点确定，等待加载完成，回到首页即可

## 四、常见问题

**Q：换台卡顿怎么办？**
A：换备用线路，本站更新公告里会注明当前最流畅的线路。

**Q：加载不出频道？**
A：检查配置地址是否填对、网络是否正常，或等本站发布更新。

**Q：多久更新一次？**
A：线路失效会不定期更新，关注公众号可第一时间收到更新通知。
